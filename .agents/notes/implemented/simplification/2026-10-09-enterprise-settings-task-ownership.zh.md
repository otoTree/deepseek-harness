# Agent Note: 企业设置按任务划分页面

Status: implemented

[English](2026-10-09-enterprise-settings-task-ownership.md) | 中文

## Problem

账户设置重复展示模型目录和个人用量，插件设置则重复展示缺少安装操作的市场目录。用户必须自行判断哪个页面负责操作。有限的用量记录页也无法得出完整月度总量。

## Decision

企业账户负责组织身份、订阅、角色和设备。模型负责默认模型选择及能力目录。通讯录负责成员、邀请和受权限控制的成员用量。账单负责共享钱包、兑换、个人近期用量和账本，并明确标注个人近期用量仅包含部分记录。企业插件设置保留可发现的入口，关闭设置后打开插件市场；市场是唯一的目录与安装界面。

[团队钱包](../feature/2026-09-18-team-cny-wallet.zh.md)和[插件市场](../feature/2026-09-19-enterprise-plugin-marketplace.zh.md)决策继续负责授权、计费和包生命周期。本决策仅涉及设置导航和呈现。

## Alternatives considered

在账户页保留摘要副本会形成相互竞争的入口，并要求用户自行核对不同统计窗口。完全删除插件设置入口则会降低在设置中寻找插件管理功能的用户的发现效率。

## Consequences

用户在一个明确入口完成各项任务。模型页在默认选择器旁展示能力限制，目录为空时禁用选择。插件设置不读取目录。个人近期用量使用已有 Host 汇总，不在浏览器中重复计算。组件快照和交互测试覆盖页面分工、模型选择、空模型、设备确认、钱包兑换和市场跳转；原生桌面验收仍独立进行。
