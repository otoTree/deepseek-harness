# Agent Note：移除企业客户端云端工作区设置

Status: implemented

[English](2026-10-09-remove-enterprise-cloud-workspaces.md) | 中文

## 问题

桌面企业客户端暴露了云端工作区设置页和对应 RPC 操作，但当前部署不提供这项能力。

## 决定

企业客户端不再注册云端工作区设置分区，也不再发送对应工作区 RPC。独立包提供的共享本地工作区功能继续可用。

## 考虑过的替代方案

**只隐藏设置入口** — 这会让不支持的 RPC 操作和 wire 类型继续留在企业客户端中。

**通过配置禁用页面** — 这会保留不支持的产品界面，并使可用性依赖部署配置。

## 影响

企业设置导航只包含企业账户、模型、团队和企业插件。企业客户端不再包含云端工作区文案、schema 或传输分发。重新引入该能力需要新的客户端与 API 决策。

## 验证

企业客户端测试现在断言工作区设置入口不存在。定向类型检查和客户端测试覆盖了此次删除。
