# Agent Note：中性客户端界面文案与标志

Status: implemented

[English](2026-09-17-neutral-enterprise-client-chrome.md) | 中文

## 问题

默认客户端与官方客户端在侧栏和 New Session 首屏显示 DeepSeek 鱼形标志，以「探索未至之境」描述空白状态，并以「深度求索中」标注模型正在运行。这些标志和措辞把特定部署身份带入了共享产品状态。企业客户端使用 AgentOS 作为名称，需要以中性的动作语言描述界面正在执行的操作。

## 决定

侧栏外壳不再提供回退标志，官方品牌插件只注册 AgentOS 名称。New Session 首屏删除 `conversation.hero.brand.mark` 槽位及其动画鱼形回退，并显示本地化的中性标题「How can I help?」/「有什么可以帮你？」。运行中的 Turn 状态使用「Processing...」/「处理中...」。部署自有包在产品确实需要图标时仍可占据侧栏的独立标志槽位，但共享组合与官方组合都不占据它。

本决定取代已交付的[首屏鱼形标志 hover 变形](../feature/2026-08-12-hero-fish-hover-swim-morph.zh.md)。该交互满足了此前让标志具有明显动画的要求，但标志已不再属于 New Session 首屏。

## 考虑过的替代方案

**保留鱼形标志但删除动画。** 静态鱼形标志仍会呈现同一个特定部署身份，因此不能满足中性客户端要求。

**用另一个默认图标替换鱼形标志。** AgentOS 名称旁或中性空白状态提示旁没有通用图标能传达有用状态。留空可以避免引入另一种装饰性身份。

**只修改企业组合。** 客户端产物陈旧的问题表明，共享客户端 bundle 与官方品牌填充会在重建后保留旧界面。直接在所属包中删除默认值，可以让每个受支持的组合都保持明确。

## 影响

官方企业客户端的侧栏与 New Session 首屏不再显示产品图标。首屏移除了 hover 变形及其品牌标志扩展点；若未来重新引入首屏图片，需要形成新的明确产品决定，而不能占据一个闲置槽位。本地化测试覆盖中性标题与运行状态，官方品牌测试要求侧栏标志槽位保持为空。
