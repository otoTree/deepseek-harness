# Agent Note: 对话下方的画布管理

Status: implemented

[English](2026-10-26-arivo-canvas-sidebar.md) | 中文

## 问题

Workbench 的画布新建和选择占用编辑面板，而分集管理已经位于对话下方。第二个管理区域打断统一工作区布局。

## 决策

启动外壳通过 `sidebar.footer.action` 注册独立的[画布列表](../../../../apps/electrobun/src/distribution/arivo-shell/client/canvas-rail.ts)。独立构建的创作编辑器发布项目范围的元数据，并保留新建、保存和切换的全部权限。外壳校验已加载的 frame、精确 origin、项目和随机绑定 ID；只有最新绑定能够发布状态或发送动作。面板释放时清除对应贡献。

## 考虑过的替代方案

把创作代码或数据库访问嵌入 Harness 会重复持久化职责。分集与画布共用消息格式会混淆不同实体和命令。在 Workbench 编辑器中保留画布管理区会重复导航；独立创作页仍使用该管理区。

## 影响

编辑器隐藏重复的管理区与返回控件，默认打开首张画布，并持有新建画布弹窗。取消不写数据；未知回执保留原命令 UUID。草稿、中文组合输入、手势和弹窗阻止切换或离页。侧栏转发新建/打开/改名/删除意图，持久化与确认仍归创作插件所有。现有发布与原生验收要求仍然保留。

## 测试

[桥接测试](../../../../apps/electrobun/tests/arivo-canvas-rail.test.ts)拒绝外来来源、origin、项目、绑定和旧回调。[打包 Workbench 验收](../../../../apps/web/tests/arivo-workbench-direct.e2e.ts)在录制对话旁回放画布新建、取消新建、丢失回执恢复、切换、中文输入保护和 slot 释放。插件独立画布验收覆盖原管理区及编辑流程。浏览器证据不代表原生窗口验收。

画布条目通过同一精确 frame 桥接提供改名和删除意图。创作 Worker 负责 CAS、不可变命令恢复及逻辑删除，侧栏只接收元数据。已删除画布保留受保护原件和历史，已受理的云端调用继续沿原生命周期处理。桥接测试拒绝这些操作中的未知画布 ID 与过期绑定。
