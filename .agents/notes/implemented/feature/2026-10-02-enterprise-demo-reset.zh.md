# Agent Note: 本地企业演示数据重置与目录样例

Status: implemented

[English](2026-10-02-enterprise-demo-reset.md) | 中文

## 问题

本地 Enterprise 数据库积累了测试账号和组织，管理端目录还缺少一套可登录的多层级企业样例。

## 决策

`apps/api/scripts/reset-enterprise-demo.ts` 在一个事务内执行本地重置。脚本保留截图中的两个账号、它们所属的组织及租户数据，并保留平台管理员；其他测试账号和租户行按外键依赖顺序删除。随后脚本创建固定 ID 的智域科技集团样例，包含三个事业群、嵌套部门和小组、成员、角色绑定、订阅和钱包。固定凭据和仅限本机的迁移地址校验让脚本可以重复执行，且不会指向远程数据库。

## 后果

本地验收数据被清理后可以重新生成，浏览器能够使用真实的 Better Auth 凭据完成验证。保留账号的凭据和运行时记录不变。演示密码只由本地种子命令输出，仅用于开发环境。
