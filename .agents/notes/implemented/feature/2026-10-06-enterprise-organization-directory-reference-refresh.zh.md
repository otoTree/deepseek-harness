# Agent Note: 组织目录参考图对齐更新

Status: implemented

[English](2026-10-06-enterprise-organization-directory-reference-refresh.md) | 中文

## 问题

组织目录之前使用通用资源组件，组织结构、组织概览、成员详情和账号详情四个视图都没有对齐参考图；账号详情也没有集中展示组织归属、角色、设备、会话、用量和审计历史。

## 决策

组织目录路由现在使用独立工作区，包含自己的顶栏、标签、指标卡、组织树、表格、详情面板和操作按钮。工作区读取平台组织、节点成员、账号、账号组织归属、运行时、会话、用量和历史 API。账号详情把账号列表中的真实状态合并到详情响应，并将 API 返回的空数据显示为破折号；费用卡读取账号用量接口中的已结算人民币 `totalCostMicrosCny`。部门结构视图请求完整的组织和单位目录，单位行返回已启用分配成员数；平台组织概览接口返回组织数、活跃成员数、管理员数、运行设备数和最近用量费用。

## 后果

四个组织视图在桌面端使用固定比例，在移动端自适应布局，不再依赖通用资源表或组织树组件。账号详情不再伪造设备、角色、费用、审计数量或活动时间。现有组织和账号 API 继续负责新建、邀请、编辑和密码操作。
