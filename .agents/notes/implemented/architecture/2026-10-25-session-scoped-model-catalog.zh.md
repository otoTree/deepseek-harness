# Agent Note：会话级建议模型目录

Status: implemented

[English](2026-10-25-session-scoped-model-catalog.md) | 中文

## 问题

Host 代次内的目录可能在云服务恢复前加载，部署默认值也可能属于另一个项目。因此，持久项目模型仍被选中时，原 composer 可能显示内部路由，并遗漏该项目其他模型选项。

## 决策

[模型目录解析器](../../../../packages/client/ui-model-selection/src/client/service.ts) 接受一个可选 Session 目录来源。两个原选择入口继续共用同一目录及原选择命令。来源只提供呈现元数据，不修改部署默认值、持久模型选择或已受理调用。Null 委托共用 Host 目录。失败读取允许重试。范围元数据不可用时，原 Host 目录只提供 provider 可达性和持久选择，其名称和选项不进入范围目录。Session 释放、来源替换和连接重置取消范围读取并抑制晚到结果。移除来源恢复共用目录。未注册来源的部署保留共用目录及重连行为。

Arivo 启动插件通过已认证的本地 RPC 注册来源。Host 从原活动 Session cwd 和已验证的原生文件夹注册推导项目权限。原生句柄验证当前云归属和已配置的工具模型，适配器只列出该计费项目的模型。跨项目路由、缺少设置、模型移除和账号更换明确失败，不能回退到另一项目的目录。未绑定的原 Harness 目录保留共用目录。目录读取不生成内容、不扣积分。

## 考虑过的替代方案

**打开项目时修改全局默认值。** 这会修改无关对话，并让并行项目选择器共用一份可变目录。范围呈现保留显式 Session 选择。

**在浏览器保存显示名称。** 缓存名称不能证明当前授权或模型可用性。原生账号所有者读取当前在线元数据。

## 结果

可选来源扩展已有选择器服务，没有新增 Agent 循环、选择器 UI 或企业账号依赖。项目数据和对话日志保留现有存储。整项目存储激活与正式原生/Windows 发布验收仍是独立工作。

## 测试

解析器测试覆盖两个并行项目、云服务恢复、默认值和选择不变、来源注册/移除、共用回退、已寻址 subagent 拒绝、连接重置、Session 释放及旧账号晚回复。原生目录测试覆盖精确计费路由、缺少设置、跨项目条目、撤销范围、取消和句柄释放。Agent 录制回放先解析范围名称，再执行原工具循环。完整包产品验收检查 Host 完整重启和云服务恢复后的可见名称。
