# Agent Note: 桌面本地会话与按请求续期的云端授权

Status: implemented

[English](2026-10-22-local-desktop-sessions.md) | 中文

## Problem

设备心跳使打开的桌面即使空闲也会产生数据库工作。云端会话写入还让本地历史和工作区可用性依赖 API。设备限额统计的是安装数量，而不是稀缺的请求容量；短期在线租约会使普通网络故障停止本地工作。

## Decision

桌面挂载标准本地 JSONL 提供方。存储身份组合规范化的 API 来源、账号 ID 和组织 ID，在更换登录令牌后保持稳定，并隔离同一电脑上的账号。普通启动恢复受保护的凭据和本地存储，不发起云端请求。退出登录会停止本地执行、尝试云端撤销并删除凭据，同时保留本地文件。远程撤销无法阻止离线读取已经保存在该电脑上的文件。

API 签发不透明、仅保存哈希且可撤销的登录授权，不设设备限额或心跳。`loginSessionSeconds` 定义闲置到期时间，默认为 30 天。实际云端认证请求检查成员资格与到期时间，并在有效期后半段延长仍有效的令牌。已到期令牌要求重新登录；登录时保存的时间戳不代表权威的服务端状态。续期不轮换令牌。模型用量、云盘访问和插件控制仍需云端授权。插件激活租约与远程存档写租约保留各自的所有权语义。

账号设置显式上传全部本地对话，并下载同一账号和组织的云端存档。每批上传在短事务中锁定存档，校验不可变元数据与重叠事件，仅追加连续后缀。这使并发上传串行化，无需持久写租约或续租流量。活跃的旧远程写入者会拒绝上传。下载在本地创建前验证完整存档，只扩展一致的持久化前缀；扩展前必须关闭活跃的本地写入者。两个方向均保留一致的较长历史并拒绝分歧。失败前完成的页面保持持久化，因此重试可以安全续传。传输不进行后台同步，不复制附件或工作区文件。每份存档在 Host 内存中组装。

[服务端权威记录](../bug-fix/2026-09-14-enterprise-client-renewed-runtime-lease.zh.md)保留凭据绑定的原因，[恢复记录](../bug-fix/2026-10-21-desktop-login-restoration.zh.md)保留按部署定位凭据的原因。本决策替代它们的在线租约生命周期。[设置恢复记录](../bug-fix/2026-10-22-desktop-heartbeat-transient-failures.zh.md)保留独立的设置导航和失败恢复原因。设备限额统计被完全替代。

## Alternatives considered

**保留云端持久化并延长心跳。** 这会降低写入频率，但仍将本地历史与启动绑定到网络和数据库可用性。

**用 Redis 设备租约替换 PostgreSQL 心跳。** 这只会将空闲流量转移到另一服务，而没有在线设备准入需求。

**保留设备上限。** 保存一份登录不预留数据库连接。有界连接池与请求准入管理实际云端并发。

**自动合并云端与本地历史。** 分歧的事件日志要求明确冲突策略。仅接受一致前缀的导入保留已有历史，并明确显示冲突。

## Consequences

本地会话持久化与桌面空闲生命周期不消耗 API 数据库连接。云端请求仍使用短事务；插件轮询和激活续租可独立产生空闲流量。本地文件需要备份，电脑之间不自动共享会话变更。云端授权到期不会停止本地运行时。存储命名空间隔离应用选择，不加密文件，也不限制操作系统用户。

## Verification

真实进程桌面测试覆盖离线重开、已到期的保存凭据、稳定账号身份、账号与部署隔离、退出登录及失败清理。真实 PostgreSQL 测试覆盖两个注册入口的无限设备注册、请求续期、到期、撤销和成员暂停。传输测试使用 JSONL 存储覆盖分页、重复传输、上传中断恢复、第二台设备下载、较长本地历史、冲突拒绝、取消和已发布事件验证。PostgreSQL 上传测试覆盖 bearer 授权、账号与租户隔离、幂等分页、缺口、分歧及活跃写入者拒绝。录制会话设置浏览器用例通过 Host 桥接覆盖上传、下载与失败恢复。[桌面 README](../../../../apps/electrobun/README.zh.md#local-session-storage)负责存储操作说明。
