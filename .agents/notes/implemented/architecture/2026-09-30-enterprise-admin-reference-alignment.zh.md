# Agent Note：Admin 参考界面采用浅色工作画布

Status: implemented

[English](2026-09-30-enterprise-admin-reference-alignment.md) | 中文

## Problem

提供的企业超级管理员界面导出使用深色导航栏和浅色工作画布，而之前的跨产品视觉基线让整个 Admin 保持深色。现有 Admin 还将多个平台页面渲染为通用 JSON 表格，组织、用量、健康和审计工作流不便于扫描。

## Decision

Admin 将共享 `ui-theme` 语义角色映射为 [Figma 改版设计](https://www.figma.com/design/oIEgfoHtGZUcZ2WhMBijP0)定义的浅色工作画布。深色导航栏分为总览、组织与账号、平台资源及平台治理。每页提供一个标题及上下文操作；供应商任务、账号详情和团队详情使用明确路由或查询视图。参考图示例数据保留在生产组件之外。

平台总览由管理员专用的单次 `/v1/platform/overview` 事务提供。接口返回统计范围、组织／成员／Runtime 与用量总数、上海时区趋势点、待办、健康行和最近审计事件。成员指标统计成员关系数。趋势图由返回的金额生成，没有趋势点时保留空状态。

现有资源 API 负责修改操作。表单保留显示的版本、审计原因、失败输入、到期语义及计费单位；GiB 容量输入在提交前转换为整数字节。弹窗表单约束键盘焦点，在允许取消时支持 Escape，并在关闭后将焦点恢复至触发控件。

面板尺寸、区块间距与导航滚动遵循[内容高度与间距决策](../bug-fix/2026-10-16-admin-content-heights-and-spacing.zh.md)。

私有化部署在 Admin 外壳提供企业 SSO 与目录同步，因为它们属于企业配置工作流。外壳要求平台管理身份，所选团队还要求有效成员关系及 `identity.manage` 或 `directory.sync`。开放部署不请求这些资源。显式选择团队避免平台身份隐含客户团队权限。身份编辑在密钥字段留空时保留已有值；差异决定保留版本并要求确认。回滚创建补偿差异，另行审批后应用。

## Alternatives considered

- **让整个 Admin 保持深色** —— 可以保留之前的色板，但无法符合提供的管理员参考界面；浅色工作区是其扫描层级的一部分。
- **在产品内直接渲染 PNG 导出图** —— 可以得到截图匹配，但没有可用、可访问的界面，也无法使用实时数据和操作。
- **由浏览器分别请求总览卡片** —— 不同请求可能来自不同时间；服务端聚合保证统计范围和事务一致。

## Consequences

- Admin 与企业客户端共享语义角色和交互状态，同时在表面明暗和信息密度上有意区分。
- 总览拥有稳定的 typed 响应和单一刷新点，详情页面继续使用各资源已有 API。
- 文案继续由 `apps/admin/app/messages.ts` 负责；参考图示例数字只用于测试 fixture。
- 本地字体和 Lucide 资源提供一致的排版与导航，页面渲染无需第三方请求。字体子集覆盖词典文案；动态名称可以使用系统回退字体。

## Verification

Admin 类型检查、所属页面快照、针对性交互测试及生产构建覆盖实现。浏览器验收使用隔离的只读 API fixture 检查页面几何与响应式布局，不代表真实修改操作已验证成功。
