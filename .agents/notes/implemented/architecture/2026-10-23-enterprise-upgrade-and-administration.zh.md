# Agent Note：保留数据的企业升级与平台套餐管理

Status: implemented

[English](2026-10-23-enterprise-upgrade-and-administration.md) | 中文

## 问题

只读取新归属记录的月度摘要会遗漏保留费用；遗漏桌面令牌路由或分页上限不一致会使有效数据无法访问。纯文本套餐不能支持目录维护。更名后的应用仍可能在钥匙串显示供应商名称。

## 决策

[迁移 0041](../../../../apps/api/migrations/0041_subscription_catalog.sql)保留已有订阅和用量，导入套餐代码，并按保留时间戳补齐缺失接纳归属。历史部门保持未知，不采用当前归属。新增归属仍不可变。平台套餐 CRUD 使用显示版本、原因和审计；已引用套餐和开通默认套餐不可删除。分配显式应用资源默认值，保留资金、消费和资产。目录编辑与停用不改写已有订阅。价格是参考金额，不自动收费。

桌面令牌授权显式包含能力读取和任务分页。用量摘要消费者遵守 API 分页上限。原生桥不可用时，设置保留可见但禁用的更新控件及恢复提示。Admin 身份复查在加载和暂时失败期间保留已挂载表单和上传；HTTP 401/403 清除保留身份，明确的非平台身份则移除管理控件。每次聚焦都重新挂载页面会丢弃浏览器持有的文件选择，并触发清理中止上传。安装包发布显示前置条件和稳定失败码；相同签名元数据重试复用草稿，已发布版本仍不可变。

macOS 凭据助手使用智域OS标签及 `com.zhiyu.os.enterprise` 服务。读取或写入匹配旧条目时移动其服务并保留访问控制记录。退出登录删除所选账号两种名称。已发布应用标识、更新认证和工作区目录保持原值。此决策部分取代[品牌决策](2026-10-21-zhiyu-desktop-brand.zh.md)的钥匙串服务保留规则；其更新身份、产物名称及工作区理由仍有效。[团队治理](2026-10-23-team-resource-admission-and-recovery.zh.md)保留授权、接纳和容量决策。

## 考虑过的替代方案

**通过重置数据库取得新默认值。** 这会丢弃独立的钱包、成员和资产历史，且不能修复路由或消费者缺陷。带记录迁移保留这些事实。

**将目录编辑应用到所有已分配团队。** 这会隐式改变约定席位和资源设置。显式分配提供可审阅的变更及审计原因。

**重命名全部技术身份或创建第二份凭据而不移动原件。** 前者破坏已部署更新信任和工作区路径；后者保留重复私密数据并可能恢复过期凭据。移动匹配钥匙串条目可保留访问控制。

## 影响

历史月份归属使用 Asia/Shanghai，不重建缺失部门历史。分配套餐不充值钱包。已有团队可保留停用套餐，直到显式变更。签名发布仍要求部署信任配置和 HTTPS；缺少签名密钥不意味着允许无签名安装包。

## 验证

独立 PostgreSQL 测试覆盖从日志 0040 携带保留用量和订阅升级、平台专属 CRUD、过期编辑、引用删除、停用分配、令牌读取和跨团队拒绝。安装包验收覆盖存储失败和重复草稿准备。客户端测试及无密钥浏览器回放覆盖账单、任务恢复和原生更新可用性。真实供应商执行和生产安装包交接需要发布凭据，仍属于独立验收。
