# Agent Note：企业管理平台基础能力

Status: implemented

[English](2026-09-30-enterprise-admin-foundations.md) | 中文

## Problem

企业管理需要持久化权限目录、组织范围角色、身份提供商记录以及目录同步记录，同时不能破坏现有角色绑定。

## 决策

企业管理平台现在拥有版本化权限目录、组织范围自定义角色、身份提供商记录以及目录同步脚本和运行记录。现有固定角色绑定保持兼容。沙箱包提供组织工作区生命周期契约和可注入后端；内存后端只用于测试，不声称提供远程执行。

## 后果

Admin 可以通过稳定的组织接口查看权限、自定义角色、身份提供商和同步脚本。独立隔离的执行 worker 部署前，同步脚本测试请求只记录明确的预览状态。生产云端执行仍需要 E2B 后端实现和带租户校验的 API 接入。

## Alternatives considered

- **只保留固定角色绑定** —— 这样无法提供版本化权限目录或组织自有的自定义角色。
- **在请求内直接执行目录脚本** —— 这样会让管理请求依赖脚本执行；隔离 worker 部署前继续保留明确的预览流程。
