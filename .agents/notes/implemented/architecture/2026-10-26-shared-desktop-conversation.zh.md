# Agent Note: 共享桌面对话区与 Bot 管理

Status: implemented

[English](2026-10-26-shared-desktop-conversation.md) | 中文

## 问题

产品自有的 Workbench 覆盖使智域OS 与 Arivo 的控件密度不同，而独立的指令和附件按钮让共享输入框显得拥挤。多个能力重叠的内置 Agent 模式也让用户难以找到能力最完整的选项。

## 决策

[共享主题](../../../../packages/client/ui-theme/src/styles/workspace.css) 通过语义属性提供紧凑 Workbench 控件与输入框展示。两个桌面发行版与 Web 均消费此样式表。Arivo 根据[外观决策](2026-10-24-arivo-shared-appearance.zh.md) 保留独立提供的色板与字体。工具执行、Session 选择和编辑器持久化保留既有归属。

输入框通过同一个添加菜单提供附件与指令。既有文件输入、上传队列、粘贴与拖放接收及指令选择仍是各自的权威实现。可继续的子代理省略附件入口；锁定 Session 禁用菜单。消息气泡使用较小圆角，过程摘要采用无边框展开控件，活动文字消费语义颜色。

Session 顶部不显示视图切换标签，Chat 不在输入框下方提供指标栏。两个桌面 profile 覆盖层禁用 `ui-trajectory`，继承的 Web 清单不会加载它。Conversation shell 向各 View 传递 `availableViews`；Chat 仅在注册了 Trajectory 时提供工具检查入口。通用 Web profile 保留上下文检查与返回对话的入口。指标保留在既有 Host 投影与每轮详情中。

共享指令菜单通过类型化 Client 字典本地化内置 Host 指令的说明与输入提示。指令名称仍是可执行标识，扩展指令保留其提供的文案。候选项和输入声明在创建时解析翻译，因此后续打开菜单会读取当前语言，无需改变 Host 目录或执行协议。

设置将 preset 页面命名为「Bot 管理」。两个桌面 profile 默认使用 `cordis`；它的组装包含标准工具，并提供运行时检查、插件实验与 Bot 创作支持。两个 profile 通过 `disabledPresets` 禁用 `standard`、`ptc` 与 `minimal`。Host 从可选目录中排除这些标识，并拒绝新建或显式切换到它们。已保存的默认项如果被禁用，则解析为启用的发行默认项。发行配置的默认项不能被禁用。

历史 Session 读取与恢复仍可访问记录中的组装文件。禁用一个选项不会删除其文件或改写 Session 历史。自定义与已安装插件提供的 Bot 只在被显式禁用时才不可选。选择验证保持在既有的单 Session 切换队列内，防止异步解析改变并发请求顺序。

仅客户端加载的[色板样式表](../../../../packages/client/ui-theme/src/styles/client-palette.css)采用 Arivo studio-ui 1.0.72 的中性表面与黑白操作。它在共享企业／Admin 基线之后、工作区展示之前加载；Admin 不导入它。菜单、用户气泡、输入框、代码、导航与控件因此使用同一色板，同时保留 Arivo 独立发行依赖。无框架启动页使用匹配的回退颜色，过程文字渐变由表面别名派生。生命周期浏览器回放记录两种外观下对话区和菜单的实际绘制颜色；设置场景负责偏好持久化。

设置使用共享的 `Select` 与 `TabGroup` 原子组件。Select 提供主题化浮层，并以隐藏的原生控件保留表单序列化、必填校验与重置行为。任务标签页保持非活动面板挂载，切换角色、预算或存储任务时保留草稿；调用方省略未授权的标签页。企业设置与本地提供方设置共用这些控件和语义色板。

## 考虑过的替代方案

**为智域OS 复制 Arivo 样式表。** 两个展示归属会逐渐偏离。语义色板别名允许共用样式表并保留产品身份。

**只在浏览器隐藏选项，或删除其组装。** 浏览器过滤仍允许创建和切换 API 选择禁用项；删除文件则会阻止历史 Session 恢复。

## 后果

共享主题有意将紧凑 Workbench 展示应用于 Web 和两个桌面外壳。桌面默认项影响新会话；历史对话保留记录中的工具。非桌面 profile 在未配置相同策略时仍可使用完整的内置 preset 目录。浏览器回放覆盖添加菜单中的指令入口，聚焦组件与 Host 测试覆盖文件选择、子代理限制、禁用选择及历史解析。打包桌面视觉验收仍独立于浏览器回放。
