# Agent Note：Arivo 项目文件夹绑定原 Harness 工作区

Status: implemented

[English](2026-10-25-arivo-project-folder-binding.md) | 中文

## 问题

账号级创作工具与独立选择的 Workbench 项目会让对话编辑其文件夹之外的内容。创作者需要项目优先的入口，同时保留原 Harness Agent 与工作区归属。

## 决策

[原生目录适配器](../../../../apps/electrobun/src/distribution/arivo-shell/host/project-folders.ts)在原应用内目录浏览器打开前校验验证后插件的账号作用域，并在外壳提交所选路径时再次验证该作用域。已验证插件拥有统一创建：选择父目录新建同名文件夹或使用已有文件夹，然后创建或验证一个云项目，持久保存不可变本地/云端映射。取消目录选择不创建项目。原操作日志恢复磁盘或网络中断，恢复不再打开目录选择器。插件也将已有本地项目绑定到唯一规范目录。原 Workspace Registry 拥有目录登记；重试相同绑定可修复中断的 Registry 确认。

项目对话操作使用稳定的对话 UUID 在已登记工作区中创建原 Harness Session。支持工具调用的在线模型和不可变云端计费 ID 来自项目设置，创建前再次验证，并通过原 Session 模型选择命令写入。已有非空对话和已受理模型步骤保留原选择。新组装请求必须符合文件夹项目的云端计费 ID；不匹配时拒绝，不默默改变计费归属。[工具适配器](../../../../apps/electrobun/src/distribution/arivo-shell/host/studio-tools.ts)从可信 Session header.cwd 派生项目。Workbench 通过 header 校验的 Registry 成员关系解析当前 Session，并打开精确项目。缺少绑定时明确失败。iframe 与模型不能提供文件系统路径。

启动 Client 打开项目中心，同时保留原对话、Skills/MCP、预设、市场和 Workbench。独立插件将创作 SQLite 与原件路由到项目文件夹，并单独记录不含凭证的云身份。Harness 仅消费构建后的发布包；账号凭证、普通对话日志与 Registry 仍在项目文件夹之外。可移植移动和内容同步属于独立工作。

## 考虑过的替代方案

**隐式当前项目。** 复用最后可见项目会在对话切换文件夹时允许跨项目编辑。原生目录绑定提供明确归属。

**立即搬迁存储。** 在项目级迁移和恢复未完成前搬动现有 SQLite、媒体与回执会危及已有工作。目录登记采用增量方式并记录存储模式。

## 影响

文件夹所选对话和 Workbench 共用项目身份，不增加第二个 Agent 循环。插件拥有账号与项目校验；OS 拥有会话与自身目录浏览器。企业组合与依赖版本不变。创建在文件夹、云身份及原 Workspace 登记完成后打开内容；登记中断时重试原命令。插件校验在线项目成员权限。项目模型及已有本地项目的云归属收纳在项目设置；通用模型默认值仍可在外壳设置中管理。可移植移动仍是未完成工作。

## 测试

原生选择测试覆盖统一创建、登记失败后无须重选目录的恢复、取消、账号替换、Registry 中断、绑定 Workbench 查询、项目对话登记、已验证模型继承，以及不同或缺失计费归属的拒绝。原工具注册测试验证 Session 派生归属、缺少目录及获取失败诊断清理。打包产品验收操作文件夹选择、原 Session 和匹配的 Workbench 项目。录制 Agent 回放在每次模型请求前检查项目计费归属，并保留本地工具执行和句柄释放。Windows 与正式发布验收独立保留。
