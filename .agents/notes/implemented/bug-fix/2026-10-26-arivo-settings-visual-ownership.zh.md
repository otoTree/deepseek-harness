# Agent Note: Arivo 设置视觉归属

Status: implemented

[English](2026-10-26-arivo-settings-visual-ownership.md) | 中文

## 问题

Arivo 账号、模型和运行环境分区共用回退齿轮图标，不透明的设置列与嵌入页重复内边距割裂产品背景。仅截取弹窗会遮住周围缺陷。

## 决策

Arivo 注册项通过现有 slot icon 选项提供语义图标。设置外壳暴露稳定数据属性，Arivo 在启动主题中拥有背景、导航与嵌入页间距。默认设置样式继续归通用外壳。账号插件提供不同导航图标、浮起弹窗与单一字段聚焦样式。

## 考虑过的替代方案

**在通用回退中匹配产品分区标识。** 这会让共享设置外壳耦合到单个发行版，并绕过现有注册选项。

**使用 CSS Module 类名片段。** 生成类名不能为产品主题提供明确的样式契约。

**接受模糊弹窗截图。** 这无法证明导航图标、页面表面或内容间距正确。

## 影响

通用外壳增加展示属性，没有增加设置状态或命令。产品验证分别覆盖无遮罩设置页和弹窗，在打包运行时检查导航图标不同、外壳背景透明。实际绘制仍需原生截图核对。
