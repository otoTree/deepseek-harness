# Agent Note: Admin 面板使用内容高度与统一间距

Status: implemented

[English](2026-10-16-admin-content-heights-and-spacing.md) | 中文

## 问题

当 Grid 将短 Admin 面板拉伸到相邻长表格的高度时，短面板会出现大片空白。页面各自定义的指标卡尺寸和纵向负 margin 也使区块关系不清晰。仅覆盖视口高度的导航背景无法覆盖长页面底部。

## 决策

Admin 内容面板顶部对齐，并随内容增高。页面级指标卡共用 128px 最小高度，在不超过 720px 的宽度下降为 112px。控件最小高度为 36px；表格操作在桌面为 32px，主要操作在手机为 44px。卡片内边距为 20px，手机降为 16px，区块间距为 24px。文本换行可以增加这些最小高度。手机顶部操作区可换行，表单轨道与输入框受面板宽度约束。

图表保留绘图区所需空间。页签和宽表格在各自容器内滚动。弹窗高度受视口约束，内部内容滚动而不扩大页面宽度。

Admin 阅读区域使用 13px/20px 正文、12px/18px 标签、15px/23px 区块标题，以及 25px/38px 页面标题。在不超过 720px 的宽度下，页面标题使用 23px/34px。数据指标与辅助信息保留各自任务所需的字号。Noto Sans SC 用于界面文案，Space Grotesk 用于指标数字。

壳层拥有覆盖整页的深色侧栏背景，以及高度为 100dvh、可独立滚动的内部 sticky 导航容器。壳层布局选择器指向直接 main 和 aside 子元素，使嵌套工作区元素保留自己的布局。移动导航使用已有抽屉，关闭状态下链接不参与键盘导航。[参考对齐决策](../architecture/2026-09-30-enterprise-admin-reference-alignment.zh.md) 继续负责浅色画布与总览数据展示。

## 考虑过的替代方案

**强制所有卡片等高。** 等高便于比较同类指标，但短上传表单与长版本表承载的信息量不同。拉伸会浪费空间，并使表单终点不清晰。

**移除所有最小高度。** 图表需要可读的绘图区，编辑器需要实用的编辑空间。内容面板可以收缩，同时保留这些与任务相关的最小尺寸。

## 影响

短面板可以在相邻长表格上方结束。共用尺寸使同类控件和指标保持一致，同时允许内容换行增高。侧栏分别承担整页背景覆盖与视口高度导航滚动两项职责。浏览器几何数据和截图归 Admin 所有，保存在 `output/playwright/admin-layout/`；CSS 文本断言无法证明实际间距或滚动行为。
