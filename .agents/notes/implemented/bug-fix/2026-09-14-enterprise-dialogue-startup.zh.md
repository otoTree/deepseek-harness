# Agent Note：企业对话启动所有权

Status：implemented

[English](2026-09-14-enterprise-dialogue-startup.md) | 中文

## 问题

企业桌面 Runtime 可能在 API 仍在启动时加载模型并申请会话租约。多个桌面 Runtime 也可能指向同一个组织目录并互相隔离会话写入方。

## 决策

企业协调器先等待 API 和管理端健康端点，再启动桌面进程。每个组织目录在 Runtime 生命周期内持有 POSIX 内核锁，因此第二个 Runtime 会明确失败，进程退出后锁自动释放。

## 备选方案

- 与远程服务并发启动桌面进程：Runtime 初始化可能访问尚不可用的模型和会话 API，因此不采用。
- 使用进程内映射检测重复 Runtime：不同协调器不会共享该状态，因此不采用。

## 影响

桌面启动不再与远程模型和会话服务竞争时序。重复的组织 Runtime 会给出可处理的所有权错误，而不是破坏远程会话租约状态。

## 测试

Runtime 生命周期套件覆盖重复组织所有权和重启释放。Runtime 类型检查通过。
