# Agent Note: 独立插件开发有一个指导入口

Status: implemented

[English](2026-10-03-independent-plugin-development-guide.md) | 中文

## 问题

插件开发指引分散在包创建、插件分类、扩展模式、包 README 和测试策略中。贡献者可以找到单条规则，但没有一条有序路径来判断独立性、选择 Service Definition / Provider / Consumer 边界、挂载真实组合、证明释放行为并更新开发索引。

## 决策

仓库在 [`docs/cookbook/developing-an-independent-plugin.md`](../../../../docs/cookbook/developing-an-independent-plugin.zh.md) 维护独立插件开发指南。该指南属于实操手册，按设计、包结构、公共约定、入口、组合、生命周期测试、包文档、索引维护和校验排列步骤。它链接到现有所有者，不复制包约定或生成目录。

开发索引为新增独立插件或能力设置专门的运行时路径行。根 `AGENTS.md` 已要求 agent 在实现前使用该索引，因此指南会通过同一个必需导航步骤被发现。指南和索引均有中文配对文件及一致性记录。

## 曾考虑的替代方案

**把指引加入 `adding-a-package.md`。** 该页面负责工作区包创建和编译器注册。加入生命周期设计、组合和索引维护后，包清单就要承担更宽的插件约定，读者也必须扫描无关的设置细节。

**把指引加入 `extension-cookbook.md`。** 该页面是工具、钩子、UI 插件和协议驱动程序的模式参考，不负责独立插件所需的有序包和发布流程。因此新指南链接这些扩展模式，但保持两个文档的范围独立。

**只把指引放进开发索引。** 索引是查找地图，不是操作流程。单独的实操手册提供一条可执行路径，同时让索引只保留一行简洁的改动到文件指引。

## 后果

贡献者有一个独立插件工作流入口，索引也会在改动类型是新增能力或插件时指出它。包清单、组合规则、生命周期测试策略或索引维护约定改变时，必须更新本指南。本指南不替代包 README、子系统页、生成参考或源代码 JSDoc。
