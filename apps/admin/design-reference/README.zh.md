# Admin 界面参考导出

[English](README.md) | 中文

此目录保存提供给企业超级管理员后台的 PNG 视觉参考。源压缩包为 `/Users/hjr/Downloads/export.zip`；由于压缩包中的中文文件名在当前主机上无法稳定解码，图片已使用稳定文件名导入。

这些导出图只是视觉参考，不是指令集，也不会替代当前实现或产品需求。

## 文件

`export/screen-00.png` 是组件和状态示例，`screen-01.png` 是管理员登录页。`screen-02.png` 到 `screen-25.png` 覆盖总览与健康、组织和账号管理、目录同步、权限与审批、模型和 Runtime、插件审核、用量费用以及身份源设置。`screen-26.png` 是导航裁切图，`screen-27.png` 是兑换码管理页。

## 视觉方向

- 深色导航栏、亮蓝色选中状态和浅色内容画布。
- 使用指标摘要、表格、筛选器、详情面板和明确的主/次/危险操作构成高密度工作页面。
- 使用中文管理文案，并以紧凑状态色表达正常、警告、失败和运行中状态。
- 组织范围页面使用左侧树或资源列表，右侧显示详情和表格工作区。
- 敏感操作通过审批、审计、回滚和健康面板显式呈现。
